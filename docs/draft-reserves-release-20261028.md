## Ручная проверка пользователем

После обновления страницы проверять на отдельных тестовых сделках, без №26788:

1. Открыть сохранённый черновик, включить редактирование, выбрать аккаунт
   со свободным резервом: резерв подставляется, после сохранения остаётся в сделке.
2. Повторить для дубля, а также сначала выбрать «В ожидании», затем аккаунт.
3. Просто открыть черновик или рабочую сделку без резерва и закрыть:
   резерв не назначается. Само включение редактирования также его не назначает.
4. При медленной сети быстро сменить аккаунт или закрыть форму:
   старый ответ не меняет новый выбор; во время подбора нельзя сохранить сделку.
5. У аккаунта без свободных резервов появляется предупреждение,
   чужой занятый резерв не подставляется.
