## Ограничение воздействия

У миграции lock_timeout=1s, statement_timeout=15s; изменение параметров атомарно.
Задача использует отдельное соединение autocommit, lock_timeout=1s,
statement_timeout=30s и общий бюджет около двух минут. Обработка очереди
прерывается по бюджету между таблицами; один SQL дополнительно ограничен 30s.
Advisory lock запрещает параллельное обслуживание. При ошибке отдельной таблицы
остальные продолжают обрабатываться, итоговый код ненулевой. Systemd повторяет
неуспешный запуск через 10 минут, максимум три старта за час.

Журнал содержит только имена таблиц, время, SQLSTATE и итоги — без DSN,
паролей или содержимого строк. Контроль результата: Result=success,
ExecMainStatus=0 и событие complete с failed=0. Наличие включённого таймера
само по себе не считается успешным выполнением.
