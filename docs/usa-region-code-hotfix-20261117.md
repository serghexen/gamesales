## Причина

После предыдущего релиза пользователь обнаружил отсутствие блока поставщика
при выборе `USA (PS) (USA)`. Первоначальная проверка и тестовые данные ошибочно
использовали код `US`. Read-only проверка production подтвердила две записи:

- `US / USA`, `is_archived = true`;
- `USA / USA (PS)`, `is_archived = false` — именно этот регион используется в форме.

Проверка существования US в предыдущем отчёте не подтверждала поддержку
активного PlayStation-региона. Полноценная проверка должна учитывать код
региона из формы и признак архива.
